# Arquivos prontos para colocar no GitHub – PortfolioHUB ## 1. Criar o repositório Nome do repositório: ```txt PortfolioHUB ``` Marque: * Public * Add a README file --- # 2. Estrutura do repositório ```txt PortfolioHUB/ │ ├── index.html ├── style.css ├── README.md │ ├── projetos-academicos/ │ └── README.md │ ├── projetos-pessoais/ │ └── README.md │ └── assets/ └── imagens/ ``` --- # 3. README.md principal Crie um arquivo chamado README.md e cole: ```md # PortfolioHUB ## Sobre Repositório criado para armazenar projetos acadêmicos e pessoais utilizando Git e GitHub. ## Tecnologias - HTML - CSS - Git - GitHub ## Objetivos - Organizar projetos - Aprender versionamento - Criar portfólio profissional - Publicar no GitHub Pages ## Estrutura - Projetos acadêmicos - Projetos pessoais - Documentação ## Autor Samuel Machado Magalhães ``` --- # 4. index.html Crie um arquivo chamado index.html: ```html PortfolioHUB

  • Calculadora Web

``` --- # 5. style.css Crie um arquivo chamado style.css: ```css body { margin: 0; font-family: Arial, sans-serif; background: #f4f4f4; } header { background: #24292e; color: white; text-align: center; padding: 40px; } main { padding: 20px; } section { background: white; margin-bottom: 20px; padding: 20px; border-radius: 10px; } footer { background: #24292e; color: white; text-align: center; padding: 10px; } ``` --- # 6. Como subir para o GitHub Abra o terminal na pasta do projeto e execute: ```bash git init ``` ```bash git add . ``` ```bash git commit -m "Primeira versão do PortfolioHUB" ``` ```bash git branch -M main ``` ```bash git remote add origin https://github.com/SEU-USUARIO/PortfolioHUB.git ``` ```bash git push -u origin main ``` --- # 7. Ativar GitHub Pages 1. Abra o repositório; 2. Clique em Settings; 3. Clique em Pages; 4. Em Source escolha: ```txt Deploy from a branch ``` 5. Escolha: ```txt main ``` 6. Clique em Save. --- # 8. Link do site Depois da publicação, o site ficará: ```txt https://SEU-USUARIO.github.io/PortfolioHUB/ ``` --- # 9. Colocar no LinkedIn No LinkedIn: * Vá em “Adicionar seção ao perfil”; * Escolha “Projetos”; * Cole o link do GitHub; * Adicione descrição do projeto. --- # 10. O que gravar no vídeo Fale: * Objetivo do projeto; * Estrutura do repositório; * Como usou Git; * GitHub Pages; * Integração com LinkedIn.
